# 3 Pillar Muscle System - Landing Page

## Original Problem Statement
Build a complete landing page for "3 Pillar Muscle System" fitness transformation course in Indonesian. Features urgency bar, hook section, pain points, storytelling, 3 pillars explanation (Training, Nutrition, Sleep), before/after photos, value stack, pricing (Rp275.000 early bird), FAQ accordion, and multiple CTAs.

## User Personas
- **Primary**: Indonesian gym beginners struggling with muscle building
- **Secondary**: Fitness enthusiasts looking for structured guidance

## Core Requirements (Static)
- Dark theme: #111111 background, #F97316 orange accent
- Fonts: Montserrat (headings), Inter (body)
- Responsive design (mobile-first)
- Indonesian language content
- No payment integration (CTA scrolls to pricing section)
